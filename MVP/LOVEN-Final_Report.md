## 1. Results Summary

The LOVEN MVP was successfully developed as a digital marketplace connecting art buyers with artists through a mobile application. Core functionalities implemented include user authentication and authorization, artwork browsing and management, artist profile management, favorites system, verification request workflow, order processing foundation, and administrative verification approval.

### Key Achievements

* Developed a Flutter-based mobile application with a feature-based architecture.
* Built a Flask backend with PostgreSQL database integration.
* Implemented JWT-based authentication and persistent login sessions.
* Created artist profile and artwork management features.
* Developed favorites functionality with real-time synchronization between frontend and backend.
* Implemented artist verification request and approval workflow.
* Added verified artist badges to improve platform trustworthiness.
* Integrated Firebase Cloud Messaging infrastructure for future notification support.
* Established scalable repository and service-layer architecture.

### Project Outcomes

* Successfully delivered the planned MVP features.
* Achieved frontend-backend integration across major modules.
* Established a maintainable and scalable codebase for future development.
* Validated the feasibility of the LOVEN platform concept through a functional prototype.

---

## 2. Lessons Learned

Throughout the development process, the team gained valuable technical and collaborative experience.

### Technical Lessons

* Consistent database schema management is critical to prevent integration issues between backend services and repositories.
* Early establishment of coding conventions and project architecture reduces technical debt and improves maintainability.
* State management using Cubit/BLoC significantly improves scalability and separation of concerns in Flutter applications.
* API contracts should be finalized early to minimize frontend-backend synchronization issues.
* Continuous testing during feature implementation helps identify integration bugs before they accumulate.

### Project Management Lessons

* Frequent communication between frontend and backend developers accelerates issue resolution.
* Breaking features into smaller milestones improves development efficiency and progress tracking.
* Pull request reviews and collaborative debugging contribute to higher code quality.
* Maintaining detailed documentation reduces onboarding time and knowledge gaps within the team.

---

## 3. Team Retrospective Highlights

### What Went Well

* Strong collaboration between frontend and backend team members.
* Successful adoption of a clear feature-based architecture.
* Efficient division of responsibilities allowed parallel development.
* Team members proactively supported each other during debugging and integration phases.
* Major MVP features were completed and integrated successfully.

### Challenges Encountered

* Backend schema changes occasionally caused integration conflicts.
* Route management and navigation issues required additional debugging effort.
* Synchronizing frontend and backend development timelines was sometimes challenging.
* Some features required rework due to evolving requirements and architecture refinements.

### Areas for Improvement

* Increase automated testing coverage for both frontend and backend components.
* Establish stricter API documentation practices from the beginning of the project.
* Conduct more frequent integration testing sessions throughout development.
* Introduce CI/CD pipelines earlier to streamline deployment and quality assurance.

### Team Reflection

Overall, the project demonstrated the team's ability to design, build, and integrate a full-stack mobile application within the project timeline. The experience strengthened technical skills in Flutter, Flask, database design, API development, and collaborative software engineering practices while providing a strong foundation for future enhancements of the LOVEN platform.
